# Freigegebene Anamnesebögen

Julia hat **vier eigenständige PDFs** freigegeben. Lege sie mit diesen exakten Namen in `assets/anamnese/` ab:

- `Anamnese_Erwachsene_Julia_Widera-Krieb.pdf`
- `Anamnese_Anhang_Erwachsene_Julia_Widera-Krieb.pdf` (**Anlage** – getrennt vom Erwachsenenbogen)
- `Anamnese_Kinder_Julia_Widera-Krieb.pdf`
- `Anamnese_Saeuglinge_Julia_Widera-Krieb.pdf`

Die Anlage zum Erwachsenenbogen bleibt unverändert und wird **nicht** mit dem Hauptbogen zusammengeführt.

**Wichtig:** Die Linkziele in `anamneseboegen.html` funktionieren erst, wenn diese vier PDFs hochgeladen sind. Erst dann über den Pull Request zusammenführen.

Die PDFs besitzen interaktive AcroForm-Felder; auf Mobilgeräten hängt das Ausfüllen vom PDF-Viewer ab. Es gibt aktuell keine automatische Übermittlung an die Praxis.
